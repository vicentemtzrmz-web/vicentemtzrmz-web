### 📌 Proyectos destacados

**🚦 Análisis de tráfico y productividad económica**
Cruce de datos de TomTom y OCDE para explorar la relación entre congestión vial y productividad económica en distintas ciudades. Limpieza y análisis con Python/Pandas, visualización con Seaborn/Matplotlib.
`Python` `Pandas` `Seaborn` `Análisis exploratorio`

Análisis del embudo de conversión de una plataforma de e-commerce: desde la primera visita hasta la compra, incluyendo cohortes de retención. Consultas SQL con CTEs y métricas de funnel.
`SQL` `CTEs` `Cohort Analysis`
